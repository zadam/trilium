An image map is a geo map drawn over an image of your own instead of a world map, such as a floor plan, a fantasy map for a tabletop game, or a diagram to annotate. Markers and shapes work as they do on a geo map, but their positions are measured on the image instead of in latitude and longitude: in the image's own pixels, or in a coordinate system of your choosing, such as the one a video game uses.

Creating an image map

  1. Upload the image as a note of its own, for example by dragging the file into the note tree. PNG, JPEG, WebP and GIF images are supported; SVG images are not.
  2. Create a geo map, or open an existing one.
  3. Open the Geo map properties dialog from the Note menu or from the settings menu of the Collection Properties.
  4. Under Background, set Type to Custom image, then choose the image note in Image note. The list only offers image notes in a format the map can draw (PNG, JPEG, WebP or GIF), and shows all of them before anything is typed.

The map then shows the image instead of the world map and opens with the whole image in view. To go back to a world map, set Type back to Vector & Raster. The image is switched off rather than removed: its relation is renamed to ~disabled:map:image, so setting Type to Custom image again brings back the same image, with its coordinates. An image that the geo map inherits from a parent note or a template can only be switched off on the note that holds it.

The image note is stored in a ~map:image relation of the geo map, which can also be added by hand.

Image size

Images are resized when they are uploaded, so by default the image of a map is at most 2000 pixels on its longer side, which can be too coarse for a detailed map. To keep an image at a higher resolution, do one of the following before uploading it:

  • In Options → Media, raise Max image dimensions or turn off Automatically compress images.
  • Upload it through the Import dialog with Compress images unchecked.

An image that was already uploaded keeps its size; upload it again after changing the settings.

The image is drawn as a single picture by the graphics card, which limits how large it can be. Images up to 4096 pixels on their longer side are safe on practically every device, and most computers handle up to 16384 pixels. On a device whose graphics card cannot hold the image, the markers and shapes still appear but the image itself does not. The Geo map properties dialog warns about an image larger than 4096 pixels, and about one that can't be used at all, such as an SVG image.

Interaction

Adding, moving and removing markers, drawing shapes, the popup view and the contextual menu work as described for the Geo Map. The camera stays over the image and can zoom in up to four times past the image's own resolution.

The features that only make sense on a real map are not available on an image map:

  • Searching the map and searching for places online.
  • Going to your location.
  • Adding GPS tracks.
  • Clicking the places the base map shows.
  • The 3D buildings.
  • Opening a location in an external map application.

The look of the marker titles follows the image: if the image is dark, turn on Dark image under Background in the Geo map properties dialog, so that the titles are drawn in a light color. This sets the #map:darkStyle label.

The Map style setting doesn't apply to an image map, so it's hidden from the settings menu of the collection while the map has an image.

Choosing the coordinate system

By default, positions are measured in pixels of the image at its original size, from its top-left corner, with x growing to the right and y growing downwards.

To use coordinates of your own instead, open the Geo map properties dialog, set Coordinates under Background to Custom, and enter the coordinates of the image's Top-left corner and Bottom-right corner. Switching to Custom starts from the image's size in pixels, so the markers stay where they are until the corners are changed. All positions are then read and written in those coordinates, including the ones shown in the contextual menu and in the popup view. To go back to pixels, set Coordinates to Image pixels.

The corners are stored in the #map:imageBounds label of the geo map as x,y x,y, with a space between the two corners, which can also be set by hand. For example:

  • A screenshot of a game map that covers x from -512 to 512 and y from -512 to 512, with y growing downwards: #map:imageBounds=-512,-512 512,512. Coordinates copied from the game can then be pasted directly into #mapPosition.
  • A world whose y grows upwards, with the origin in the middle of the image: #map:imageBounds=-2000,1000 2000,-1000. A top-left y larger than the bottom-right one is what flips the axis.
  • A floor plan measured in meters: #map:imageBounds=0,0 24,12.

The two axes don't have to use the same scale. A circle is always measured in the map's own units, so it appears as an ellipse when the units are stretched differently along the two axes.

Corners that share an x or a y don't span an area: the dialog doesn't save them, and a label holding them, or a value that cannot be read, is ignored and the pixels of the image are used instead.

Coordinate rulers

Enabling Show scale in the collection properties draws rulers along the edges of the image instead of a distance scale. Round values of the map's coordinates are marked with ticks along all four edges, labeled along the top and left ones, with faint grid lines across the image. The spacing follows the zoom level, and the values follow #map:imageBounds when it is set.

The rulers are drawn on the image itself, so they move out of view along with its edges when zooming in. The grid lines remain visible across the image.

How the positions are stored

Because positions are stored in different labels from the ones of a geo map, the same note can be placed both on a geo map and on an image map.

The positions belong to the coordinate system, not to the image. When replacing the image with a different one, for example a higher-resolution copy, keep #map:imageBounds describing the area the new image covers and every marker stays in place. With Image pixels, the positions are pixels, so an image of a different size moves the markers relative to what the image shows; to avoid that, switch Coordinates to Custom before replacing the image, which keeps the size of the old one (0,0 <width>,<height>) as the corners.

To draw freely over an image instead of placing notes on it, consider a Canvas.
