Downloaded resources are large files that some features need but that do not ship with Trilium, such as the speech recognition models used to transcribe meetings. Trilium downloads them the first time a feature needs them, and keeps them on the device for later use.

Currently, only meeting transcription on the desktop application uses downloaded resources:

Downloading resources

When a feature needs resources that are not on the device yet, Trilium asks before downloading them. The dialog lists each resource with what it is used for, where it is downloaded from, its license and its size, followed by the total download size and the free space on the disk.

  • To start the download, press Download. Each resource shows its progress, and the feature continues once all of them are downloaded.
  • To stop the download, press Cancel or close the dialog. The files already downloaded are kept, and the next download continues where this one stopped, even within a large file.
  • If the disk does not have enough free space, the dialog says so and the download cannot be started.

Every file is checked against a checksum built into Trilium before it is used, so a file that was damaged or altered during the download is discarded.

Downloaded resources are not synchronized. Each device that uses a feature downloads its resources separately, even when the notes are kept in sync through Synchronization.

Managing downloaded resources

To see the downloaded resources, go to Options → Downloaded resources. Each resource that was downloaded, or partly downloaded by an interrupted download, is listed with its size and its status. Below the list, Space used shows the space they take in total, and how much free space is left on the disk.

  • To open the folder of a resource, press the button (desktop only).
  • To delete a resource, press the button. If a feature needs it again, it is downloaded again.

The list also shows, faded out, anything else in the resources folder:

  • Older version: the files of an earlier version of a resource. When a resource is updated, the new version is downloaded into a new folder, and the old one is left behind.
  • Not used: a resource that no feature of this installation uses, for example one downloaded by a feature that was removed.
  • Unknown: any other file or folder, for example one copied there by hand.

These can be deleted in the same way.

If a server and a desktop application share the same data directory, a resource used by only one of them shows as Not used in the other. Deleting it there removes it for both.

Location

The resources are stored in the resources folder of the Data directory, one folder per resource. To store them elsewhere, set the TRILIUM_RESOURCES_DIR environment variable to another folder before starting Trilium.

Installing without an Internet connection

To install a resource on a device that cannot download it, copy its folder from the resources folder of a device that already has it into the same place on the other device. The next time a feature asks to download it, press Download: the files already in place are checked against their checksums and kept, and only the missing ones are downloaded.
